# GHAND APP
## Somos um app focado na maximização das atividades cotidianas relacionadas a fornecedores.
### O App oferece o controle e gestão de sua agenda de fornecedores, desde a marcação de futuras entregas até ao controle de pagamentos futuros.
### Centralizamos as informações de contatos dos fornecedores para facilitar a visualização das informações, o controle de recebimento de seus produtos e controle de futuros pagamentos.

## Tecnologias utilizadas:
### Kotlin
### Room
### Retrofit
### Android

## Pré Requisitos
- Kotlin
- Android Studio
- Emulador próprio/celular Android 5
